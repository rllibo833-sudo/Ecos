# Teknologi dan Sistem ECOS

**Kanon induk:** [Teknologi identitas ECOS](../02-dunia-dan-geografi/00-kanon-induk-dunia-ecos.md#10-teknologi-identitas-ecos).  
**Prinsip lintas-sistem:** [Prinsip Teknologi Dunia ECOS](./00-prinsip-teknologi-dunia.md).

## Baca cepat: peran teknologi

- **LynOS** — lingkungan digital yang Rezman gunakan melalui perangkat genggam.
- **Digital Forensic** — pekerjaan investigasi Rezman: memeriksa artefak, menjaga bukti, menyusun kronologi, dan menguji hubungan.
- **Living Shared Knowledge Graph** — menghubungkan orang, tempat, peristiwa, bukti, ilmu, dan teknologi dengan asal-usul serta tingkat kepastian.
- **Bahasa .cuk / Bahasa Cuk** — bahasa pemrograman khas ECOS, terutama dalam lingkungan teknis dan kota besar.
- **PusingCuk AI** — asisten untuk membantu pekerjaan terkait Bahasa Cuk; bukan sumber kebenaran mutlak.
- **Cuk Reality Engine** — sistem/fasilitas pengujian khusus, termasuk pengujian “determinan”; mekanisme rinci masih terbuka.
- **Mnemos-RLI** — rujukan konseptual untuk pencatatan dan perbandingan bukti/jejak perubahan.
- **Steadfast** — tetap alat tata kelola repositori di sisi pengembangan; belum ditetapkan sebagai teknologi in-world.

## Alur cerita teknologi

**LynOS → investigasi Digital Forensic → pemeriksaan dan pencatatan bukti → Living Shared Knowledge Graph → petunjuk ke fasilitas/riset Cuk Reality Engine.**

Alur ini adalah hubungan naratif yang direncanakan, bukan klaim bahwa semua sistem sudah diimplementasikan atau terhubung secara teknis.

## Aturan pengembangan

1. Kanon menetapkan **peran fiksional**, bukan mengklaim kemampuan repo nyata sudah selesai.
2. Jangan menambah visual atau gameplay spesifik sebelum fungsi, batas, dan konsekuensi teknologi terkait jelas.
3. Jangan memperlakukan isi folder arsip sebagai sumber kanon aktif. Gunakan arsip sebagai riwayat, lalu rujuk peran terbaru pada kanon induk.
4. Nama repositori bukan bukti integrasi. Integrasi harus memiliki kontrak data, batas izin, implementasi, dan hasil uji yang dapat diperiksa.
