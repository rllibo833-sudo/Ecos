# ECOS — Lore dan Worldbuilding

ECOS dikembangkan melalui dokumentasi lore dan worldbuilding secara bertahap. **Prioritas aktif saat ini adalah Visi dan Narasi, lalu Dunia dan Geografi.** Domain lain diparkir dalam arsip kerja agar tidak menarik fokus sebelum fondasi dunia siap.

## Aturan kerja

- Kerjakan satu domain dan satu dokumen pada satu waktu.
- **Visi dan Narasi adalah acuan utama** untuk semua domain.
- Bedakan **canon/keputusan**, **kerangka kerja**, **usulan**, **pertanyaan terbuka**, dan **implementasi terverifikasi**.
- Jangan mengklaim implementasi teknis hanya karena ada dokumen konsep.
- Jangan mengarang detail yang belum diputuskan, termasuk 25 legenda.
- Dokumen lama dipertahankan; status arsip berarti ditunda, bukan dihapus.
