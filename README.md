# ECOS — Lore dan Worldbuilding

ECOS dimulai sebagai dokumentasi lore dan pembangunan dunia fiksi. Repo ini memprioritaskan konsistensi dunia sebelum implementasi game diputuskan.

## Cara kerja
- Fokus pada satu domain dalam satu waktu.
- Bedakan **canon**, **usulan**, **belum diputuskan**, dan **terverifikasi**.
- Jangan mengklaim implementasi teknis hanya karena ada dokumen konsep.
- Catat sumber dan alasan untuk keputusan canon.
