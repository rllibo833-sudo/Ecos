# Roadmap — Integrasi Proyek

Roadmap domain **Integrasi Proyek** dalam lore ECOS. Kerjakan satu item pada satu waktu dan catat ketergantungan bila ada.

> Status awal: **Belum dirancang / belum diverifikasi**. Checklist ini adalah roadmap, bukan klaim bahwa isi atau fitur telah selesai. Centang setelah hasilnya ditulis dan ditinjau.

## Roadmap

- [ ] Daftarkan proyek yang dirujuk.
- [ ] Catat sumber resmi deskripsi proyek.
- [ ] Bedakan hubungan tematik dan integrasi teknis.
- [ ] Definisikan alasan hubungan dengan ECOS.
- [ ] Catat pertukaran data yang masih berupa konsep.
- [ ] Jangan mengasumsikan API atau server yang belum diverifikasi.
- [ ] Catat ketergantungan dan risiko.
- [ ] Tetapkan bukti minimum status terintegrasi.
- [ ] Catat tanggal dan versi sumber.
- [ ] Audit klaim sebelum publikasi.
