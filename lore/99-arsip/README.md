## Aturan arsip

1. Dokumen arsip tidak boleh diperlakukan sebagai sumber kanon aktif.
2. Jangan menghapus riwayat hanya karena dokumen lama sudah tidak dipakai.
3. Jika suatu ide diarsipkan ingin dipakai lagi, pindahkan substansi yang sudah ditinjau ke dokumen aktif dan selaraskan lintas-domain.
4. Folder arsip tidak berarti seluruh ide di dalamnya salah; statusnya hanya bukan acuan terkini.
