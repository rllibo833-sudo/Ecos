# Teknologi dan Sistem ECOS

Indeks dan aturan umum domain teknologi.

> Status awal: **Belum dirancang / belum diverifikasi**. Checklist ini adalah roadmap, bukan klaim bahwa isi atau fitur telah selesai. Centang setelah hasilnya ditulis dan ditinjau.

## Roadmap

- [ ] Definisikan tingkat kemajuan teknologi dunia ECOS.
- [ ] Catat prinsip teknologi yang berlaku umum.
- [ ] Bedakan teknologi sehari-hari dan teknologi khusus.
- [ ] Dokumentasikan batas sumber daya, akses, dan biaya.
- [ ] Catat dampak teknologi terhadap masyarakat.
- [ ] Catat risiko dan bentuk kegagalan yang masuk akal.
- [ ] Gunakan file terpisah untuk setiap sistem.
- [ ] Jaga konsistensi istilah antardokumen.
- [ ] Pastikan relasi antarsistem memiliki alasan lore.
- [ ] Jangan klaim integrasi nyata tanpa bukti.
