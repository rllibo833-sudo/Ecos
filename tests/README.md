# Pemeriksaan Konsistensi ECOS

Folder ini berisi pemeriksaan ringan untuk aturan yang sudah tertulis dan dapat diuji tanpa game engine.

- `test_world_contract.py` memeriksa aritmetika luas, hubungan kawasan masjid dengan wilayah inti, status posisi Juailin, dan penegasan bahwa geometri final belum ditetapkan.
- Tes ini tidak membuktikan peta nyata, gameplay, atau integrasi teknologi.
- Jangan menambahkan pemeriksaan yang menganggap placeholder sebagai kanon.
- Saat kanon spasial berubah, perbarui kontrak dan tes secara bersamaan.
